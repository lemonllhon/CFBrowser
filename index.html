不只是多开浏览器，

06 推荐使用流程

四种方式，
把能力用起来。

从手动管理一个浏览器环境，到让外部系统接管多个实例，Trace Browser 为不同阶段准备了清晰的起步路径。

01

手动管理

手动管理浏览器环境

  1. 准备或扫描浏览器内核
  2. 导入代理，创建实例并配置指纹
  3. 启动、保存快照或备份
02

多账号运营

批量运营多个账号

  1. 按国家、业务或账号类型分组
  2. 配置代理路由与标签规则
  3. 批量启动并使用窗口联动
03

RPA 自动化

搭建 RPA 自动化流程

  1. 启动专用实例并拾取页面元素
  2. 编排节点、条件、循环和采集
  3. 试运行后创建计划与任务
04

外部接入

通过外部系统接入

  1. 检查 /api/health
  2. 按 Code、标签或分组启动实例
  3. 用 cdpUrl 交给 Playwright 或 Selenium

02指纹浏览器实例+

实例是 Trace Browser 里最小、最清晰、可以独立流转的环境。

  • 创建、编辑、复制、删除、启动、停止、重启与详情查看
  • 配置名称、用户数据目录、分组、浏览器内核、代理、启动页
  • 设置指纹、标签、关键字与 Launch Code
  • 列表分页、过滤、列显隐、排序、顺序调整与批量启动 / 停止 / 删除
  • 查看运行状态、进程 PID、调试端口、最近错误与启动耗时
  • 运行中居中窗口、切换代理、打开已有标签页、打开 URL、接入 CDP
  • 支持并发控制，避免大量实例同时启动导致资源争抢
03指纹与设备画像+

让身份、设备和网络信号在一个实例里保持可解释的一致性。

  • 浏览器品牌：Chrome、Chromium、Edge、Brave、Opera、Vivaldi
  • Windows、macOS、Linux 操作系统画像、语言地区、时区与指纹种子
  • 按地区联动语言、时区、字体建议；支持预设和自定义覆盖
  • 虚拟架构、系统版本画像 ID、报告路径、虚拟字体目录与字体模式
  • 屏幕分辨率、色深、CPU 核心数、设备内存、触摸点数
  • WebGL 供应商 / 渲染器、Canvas / Audio 噪声、WebRTC、DNT、媒体设备与字体列表
  • 指纹一致性检查：系统、WebGL、语言、时区与字体的冲突提示
  • 复制实例时可重新生成种子、随机完整画像，或保留原指纹；支持启动时自动生成硬件画像
04代理池与代理路由+

把代理当作可检测、可分配、可追踪的网络资源，而不是一串临时文本。

  • 手动添加与批量导入 HTTP、HTTPS、SOCKS5 代理
  • 粘贴 Clash YAML，导入订阅 URL、Base64、vmess、vless、trojan、Shadowsocks、hysteria2、AnyTLS 等内容
